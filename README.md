# Project Vision
Team Project: 
Group 1's Airline Reservation System 
Project Vision:
FOR an airline WHO needs a seat reservation management system, Group 1 Reservations is software written in Java THAT provides seat status in real-time, reservation tracking, pricing options, and a user-friendly booking interface. UNLIKE other services or package software products, OUR product provides an easy-to-use capable interface with a cost-effective solution.
